Tic-Tac-Toe in C++

Description

    This is a simple command-line Tic-Tac-Toe game implemented in C++. The game allows two players to take turns and place their marks ('X' or 'O') on a 3x3 board until there is a winner or the game ends in a tie.

Features

    Two-player turn-based gameplay
    
    Input validation to ensure valid moves
    
    Detection of winning conditions (horizontal, vertical, and diagonal)
    
    Displays the game board after each move
    
    Handles tie scenarios

How to Play

    Run the program.
    
    Players take turns entering row and column indices (0-2) to place their mark.
    
    The game board updates after each move.
    
    The game announces a winner when three marks align or ends in a tie if the board is full.
